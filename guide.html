Run, compare and reproduce

A local Python application, using the standard library. Run from the extracted economy-lab folder. No financial API key or package installation is required. This is edition 2; the previous version is preserved separately.

Start

python3 hard_money_forrester_with_knobs.py

The launcher opens http://127.0.0.1:8765. Keep the terminal running. Use --port 8766 if that port is already occupied, or --no-browser to suppress opening a browser. Stop with Ctrl+C. Directly opening index.html displays the included example; new computations and validated data imports need the local server.

Begin with the explanation

The default Understand the change view offers seven plain-language questions. Run a guided example, inspect its changed assumptions and timing, then choose a stage of the mechanism map. Each stage shows actual reference/alternative values, its rule type and equation. Earnings and value bridges reconcile the selected-year differences; the today valuation has its own label. Advanced parameters remain in Build an experiment. Cases and exports are in the toolbar disclosure. How to read the lab explains the full journey.

One useful workflow

  1. Start from the reference. Select a named economic archetype and inspect its source, limitation and exact changed values.
  2. Use archetype strength or the political/economic component sliders. They apply explicit parameter mappings, not measured party positions.
  3. Choose a shock. Individual assumptions edit the alternative; horizon and time step are shared.
  4. Click Run comparison. Changed-but-unrun inputs are labelled; exports are disabled until results match.
  5. Inspect the six transmission stages, then Work and wealth, Markets and multiples, Money plans and Accounts.
  6. Move the year control or press Play. Animation reveals an already computed path; it never starts on its own.
  7. Save the case and export results. Markets and multiples also exports aggregate and issuer valuation tables with currency, source and as-of metadata. Undo restores prior inputs; Reset restores defaults while preserving Undo.

Set inputs as reference pins the current policy assumptions as the new comparison baseline. The selected shocks remain on the alternative. Opening ownership allocations, reserve institutions and financial stocks define different initial economies; they are not free within-run transfers.

Meaningful experiment prerequisites

For household debt pressure and the lower nominal target experiment, set Household borrowing stock above zero under Opening stocks. For a land-tax incidence experiment, set a positive land rent share. A rate or tax on a zero stock/base has no direct effect. All default experiments complete in the stated model domain, but arbitrary combinations need not. An error retains the previous run and identifies the unsupported assumption or boundary.

Issuer inputs

Use Markets and multiples → Import issuer JSON, starting with the template. Supply one reporting currency, a quote currency, source and as-of date, sales, operating cost/reinvestment assumptions and all financing claims. Use null for unknown claims rather than zero. The company is illustrative until identified, sourced inputs are provided. Differing currencies require quote-to-reporting FX. Clear currency metadata does not verify that imported numbers actually have those units.

Choose excess cash, not operational cash needed to support the forecast. Do not add a capitalised lease liability to cash-rent operations without matching the operating cash flow; this implementation withholds that bridge. A reference market quote divided by future forecast earnings is labelled accordingly.

Observed macro context

Refresh FRED snapshot reads official public pages and preserves the previous snapshot on failure. Import quarterly CSV accepts the labelled series in the CSV template. Four expenditure series need a common quarter. Apply three ratios explicitly to change government purchases, investment and net exports. No other assumptions become estimated. GDP expenditure ratios are not company valuation inputs.

Reproduce a saved case

python3 hard_money_forrester_with_knobs.py --case my-case.json
python3 hard_money_forrester_with_knobs.py --case my-case.json --csv results.csv
python3 -m unittest discover -s tests -v

The KNOBS section in the launcher remains editable. SCENARIO_KNOBS can hold an alternative opening policy; ISSUER_KNOBS can hold issuer settings. Case JSON preserves both paths, shock timing, issuer assumptions and archetype metadata. CSV exports contain all core time-series fields for both paths. The issuer and account tables can be reproduced from the saved case using laboratory.analyse.
