# Repository instructions

This is a public, permission-required product. Preserve LICENSE and the rights notices. Do not replace them with an open-source license or grant new reuse rights without the owner's explicit authorization.

Private font software is deliberately excluded. Do not add font binaries, private notebooks, credentials, imported private data, absolute personal machine paths or working-directory artifacts. The public edition uses Times New Roman from the viewer's system. Typeface use elsewhere requires separate permission.

Keep identities separate from behavioral assumptions and historical claims. Fisher and Benes–Kumhof are original transition illustrations; the dynamic core does not replicate their full models. Do not present synthetic political mappings or conditional valuations as empirical estimates.

For model changes run `python3 -m unittest discover -s tests -v`. For JavaScript changes also run `node --check app.js` and verify the affected interaction in the browser. Preserve source dates, units, missingness, financing counterparts and the explicit model boundaries.

Repository README and workflow files use their standard Markdown/YAML formats. User-facing research documents remain HTML: Times New Roman, a single type size, black on white, a closed rectangular frame and tight proportional spacing.
